## 本项目用到的 4 张

| 文件 | 用途 | 可见内容占比 |
|---|---|---|
| `smoke_09.png` | 水墨的主墨团 | 73% |
| `smoke_05.png` | 水墨的卫星墨点 | 78% |
| `smoke_01.png` | 水墨的淡墨（另一个卫星墨点） | 74% |
| `star_05.png` | 赛博的中心光 | 62% |

`circle_03.png` 现在是**备用**——曾用于霓虹的柔光，那圈光环已经撤掉、改回纯光束错位。
它没有被 `render.ts` import，所以不会进构建产物，留着只是为了以后要光圈时随手可用。

## 两个容易踩的点

**1. 原图是白色灰度、带透明通道。**

运行时由 `src/core/render.ts` 的 `tinted()` 按当前主题的判定色染一份（先用
`source-in` 保住形状、再填色），结果按「颜色 + 贴图」缓存。所以同一张贴图在水墨
主题下是墨、在赛博主题下就是荧光光晕。

**2. 画布边长 ≠ 视觉大小。**

贴图自带透明边距，实际内容只占画布的 62%~78%（见上表）。代码里写的绘制尺寸是
**画布尺寸**，肉眼看到的是它乘以占比。核算"特效会不会漫进隔壁轨道"时必须按
**可见尺寸**算——这条硬约束写在 `render.ts` 的 `EffectStyle` 注释里（可见半径
不得超过半个轨宽）。

## 换素材

从原包里挑一张放进来、在 `TEXTURE_SRC` 里加一条即可。原包还有 `fire` / `spark` /
`scorch` / `twirl` / `magic` / `muzzle` / `slash` 等系列没用上。
